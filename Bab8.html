Xiaoyu's Classroom · 语法解析与核心句型
Panduan komprehensif tata bahasa Bab 8: Rumus aktivitas di tempat, perbandingan fungsi "在", catatan penggabungan kata satuan, dan modal "能":
1
Rumus Tata Bahasa: Aktivitas di Suatu Tempat
Grammar Structure: S + 去/在 + Tempat + Aktivitas
1. Rumus Pergerakan Berarah:
Subjek + 去 (qù) + Keterangan Tempat + Aktivitas / Kata Kerja
(Subjek + pergi ke + keterangan tempat + aktivitas/kata kerja)
• 我去医院看病。(Wǒ qù yīyuàn kàn bìng. = Saya pergi ke rumah sakit untuk periksa/berobat.)
• 他去学校上课。(Tā qù xuéxiào shàngkè. = Dia pergi ke sekolah untuk masuk kelas.)

2. Rumus Tempat Terjadinya Aksi:
Subjek + 在 (zài) + Keterangan Tempat + Kata Kerja
(Subjek + berada/di + keterangan tempat + kata kerja)
• 我爸爸也在医院工作。 (Wǒ bàba yě zài yīyuàn gōngzuò. = Papa saya juga bekerja di rumah sakit.)
• 我在学校吃午饭。(Wǒ zài xuéxiào chī wǔfàn. = Saya makan siang di sekolah.)
2
Catatan Tambahan: Perbandingan Penggunaan Kata "在" (zài)
Grammar Note: 在 + Tempat + Verb vs 在 + Verb
Pola A: Menunjukkan Lokasi Aktivitas (Subjek + berada di tempat + kerja)
👉 爸爸在医院工作 (bàba zài yīyuàn gōngzuò)
Arti: Papa kerja di rumah sakit.

Pola B: Menunjukkan Aktivitas Sedang Berlangsung (Subjek + sedang + kata kerja)
👉 爸爸在工作 (bàba zài gōngzuò)
Arti: Ayah sedang kerja.

Contoh Berpasangan:
• 我在学校吃午饭 (Saya makan siang di sekolah) ↔ 我在吃午饭 (Saya sedang makan siang).
• 她在图书馆看书 (Dia membaca buku di perpustakaan) ↔ 她在看书呢 (Dia sedang membaca buku).
3
小语助力：量词可以和指示代词直接组合
Liàngcí kěyǐ hé zhǐshì dàicí zhíjiē zǔhé.
Aturan Satuan: Kata satuan (measure word) dapat langsung digabungkan dengan kata ganti penunjuk (demonstrative pronouns).
• 这 (zhè) + 只 (zhī) → 这只 (zhè zhī) = yang seekor ini (contoh: 这只小猫 = anak kucing ini).
• 那 (nà) + 只 (zhī) → 那只 (nà zhī) = yang seekor itu (contoh: 那只小狗 = anjing itu).
• 这 (zhè) + 个 (gè) → 这个 (zhè ge) = yang ini (contoh: 这个人 = orang ini).
• 那 (nà) + 本 (běn) → 那本 (nà běn) = yang itu (contoh: 那本书 = buku itu).
4
方位词：Kata Penunjuk Arah dan Posisi
Fāngwèicí: Kata Benda + 方位词
Letakkan kata benda di depan, lalu diikuti kata posisi:
• 房间外 (fángjiān wài) = di luar kamar.
• 桌子下 (zhuōzi xià) = di bawah meja.
• 书店前 (shūdiàn qián) = di depan toko buku.
• 医院里 (yīyuàn lǐ) = di dalam rumah sakit.
• Catatan Satuan: Hewan kecil menggunakan 只 (zhī), sedangkan hewan besar menggunakan 头 (tóu) (misal: 一头大象 = seekor gajah).
5
助动词“能”：Menyatakan Kemampuan atau Kesempatan
Modal Verb "néng": S + 能 + Verb
• Positif: 下午两点我能到。(Jam dua siang saya bisa sampai.)
• Negatif: 对不起，我不能去。(Maaf, saya tidak bisa pergi.)
• Tanya: 下午两点你能到吗？(Jam dua siang apakah kamu bisa sampai?)

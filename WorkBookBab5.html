📌 1. Tone Sandhi of "不" (bù) · "不" 的变调
不
Kaidah Dasar & Perubahan Nada · 变调规则
Rangkuman dan penjelasan mengenai kaidah perubahan nada (Tone Sandhi) untuk karakter “不” (bù).
📖 Aturan Dasar Tone Sandhi “不” (bù):
1. Nada Asli (Nada 4 / bù):
Diucapkan dengan nada keempat saat berdiri sendiri (used independently), atau ketika berada di depan suku kata yang bernada 1, nada 2, atau nada 3.
2. Perubahan Nada (Menjadi Nada 2 / bú):
Ketika karakter “不” (bù) diletakkan di depan suku kata yang bernada keempat (fourth-tone syllable), nadanya berubah menjadi nada kedua (bú).
bù ( 不 ) Nada 4 ↘
+
Nada 4 (四声) shì, huì, dà, duì
➔
bú ( 不 ) Berubah Nada 2 ↗
+
Nada 4 (四声) Tetap Nada 4 ↘
🗣️ Contoh Latihan Pengucapan (Tone Sandhi dalam Praktik):

Semua contoh di bawah ini menunjukkan “不” (bù) diikuti oleh suku kata bernada 4, sehingga pengucapannya berubah menjadi bú (klik kartu untuk mendengarkan lafal):

不是
bù + 4 → bú
bù shì ➔ bú shì
Bukan / Tidak adalah
bù ( 不 ) + shì ( 是 ) → bú + shì ( 不是 )
不会
bù + 4 → bú
bù huì ➔ bú huì
Tidak bisa / Tidak akan
bù ( 不 ) + huì ( 会 ) → bú + huì ( 不会 )
不大
bù + 4 → bú
bù dà ➔ bú dà
Tidak besar
bù ( 不 ) + dà ( 大 ) → bú + dà ( 不大 )
不对
bù + 4 → bú
bù duì ➔ bú duì
Tidak benar / Salah
bù ( 不 ) + duì ( 对 ) → bú + duì ( 不对 )
📌 2. Tone Sandhi of "一" (yī) · "一" 的变调
一
Kaidah Nada Asli & Perubahan Nada · 变调规则
Rangkuman dan penjelasan mengenai kaidah perubahan nada (Tone Sandhi) untuk karakter “一” (yī).
📖 Aturan Dasar Tone Sandhi “一” (yī):
1. Nada Asli (Nada 1 / yī):
Karakter “一” (yī) diucapkan dengan nada pertama ketika berdiri sendiri, digunakan di akhir kata, atau ketika berfungsi sebagai angka ordinal/urutan (misalnya nomor satu, lantai satu).
2. Perubahan Nada (Menjadi Nada 4 / yì):
Ketika karakter “一” berada di depan suku kata yang bernada 1, nada 2, atau nada 3, nadanya berubah menjadi nada keempat (yì).
3. Perubahan Nada (Menjadi Nada 2 / yí):
Ketika karakter “一” berada di depan suku kata yang bernada 4 (fourth-tone syllable), nadanya berubah menjadi nada kedua (yí).
yī ( 一 ) Nada 1 ̄
+
Nada 1 / 2 / 3 xiē, nián, kǒu
➔
yì ( 一 ) Berubah Nada 4 ↘
yī ( 一 ) Nada 1 ̄
+
Nada 4 (四声) gè, rì, suì
➔
yí ( 一 ) Berubah Nada 2 ↗
🗣️ 1. Diikuti Suku Kata Nada 1, 2, atau 3 (Berubah menjadi Nada 4 / yì):

Ketika kata berikutnya bernada 1, 2, atau 3, karakter “一” dilafalkan turun tegas menjadi yì (klik kartu untuk mendengarkan lafal):

一些
yī + 1 → yì
yī xiē ➔ yì xiē
Beberapa
yī ( 一 ) + xiē ( 些 ) → yì + xiē ( 一些 ) — Diikuti nada 1
一年
yī + 2 → yì
yī nián ➔ yì nián
Satu tahun
yī ( 一 ) + nián ( 年 ) → yì + nián ( 一年 ) — Diikuti nada 2
一口
yī + 3 → yì
yī kǒu ➔ yì kǒu
Sekutupan / Suapan / Mulut
yī ( 一 ) + kǒu ( 口 ) → yì + kǒu ( 一口 ) — Diikuti nada 3
🗣️ 2. Diikuti Suku Kata Nada 4 (Berubah menjadi Nada 2 / yí):

Ketika kata berikutnya bernada 4, karakter “一” dilafalkan naik meluncur menjadi yí (klik kartu untuk mendengarkan lafal):

一个
yī + 4 → yí
yī gè ➔ yí gè
Sebuah / Seorang
yī ( 一 ) + gè ( 个 ) → yí + gè ( 一个 ) — Diikuti nada 4
一日
yī + 4 → yí
yī rì ➔ yí rì
Satu hari
yī ( 一 ) + rì ( 日 ) → yí + rì ( 一日 ) — Diikuti nada 4
一岁
yī + 4 → yí
yī suì ➔ yí suì
Satu tahun usia
yī ( 一 ) + suì ( 岁 ) → yí + suì ( 一岁 ) — Diikuti nada 4

Bagian 2 Latihan Tone Sandhi “不” (bù)
📌 Catatan Kaidah: Karakter “不” (bù) yang biasanya bernada 4 akan berubah menjadi nada 2 (bú) jika berada di depan suku kata yang bernada 4. Di depan nada 1, 2, atau 3, tetap dibaca nada 4 (bù).

bùyào ➔ búyào

不客气
bù + 4 → bú
bù kèqi ➔ bú kèqi
Sama-sama / Jangan sungkan
bù + kè (nada 4) → bú kèqi (berubah jadi nada 2)

bù hē

不知道
bù + 1 → bù

不好听

Bagian 3 Latihan Tone Sandhi “一” (yī)
📌 Catatan Kaidah: Karakter “一” (yī) berubah menjadi nada 4 (yì) di depan suku kata nada 1, 2, atau 3; dan berubah menjadi nada 2 (yí) di depan suku kata nada 4.

yī + 1 → yì
yītiān ➔ yìtiān
Satu hari
Diikuti nada 1 (tiān), berubah menjadi nada 4 (yì)
一元
yī + 2 → yì
yī yuán ➔ yì yuán
Satu yuan
Diikuti nada 2 (yuán), berubah menjadi nada 4 (yì)
一点儿
yī + 3 → yì
yīdiǎnr ➔ yìdiǎnr
Sedikit
Diikuti nada 3 (diǎn), berubah menjadi nada 4 (yì)
一半
yī + 4 → yí
yībàn ➔ yíbàn
Setengah / Separuh
Diikuti nada 4 (bàn), berubah menjadi nada 2 (yí)
一车
yī + 1 → yì
yī chē ➔ yì chē

Diikuti nada 1 (chē), berubah menjadi nada 4 (yì)
一人
yī + 2 → yì
yī rén ➔ yì rén
Satu orang
Diikuti nada 2 (rén), berubah menjadi nada 4 (yì)
一碗
yī + 3 → yì
yī wǎn ➔ yì wǎn
Satu mangkuk
Diikuti nada 3 (wǎn), berubah menjadi nada 4 (yì)
一下
yī + 4 → yí
yīxià ➔ yíxià
Sebentar / Sekali
Diikuti nada 4 (xià), berubah menjadi nada 2 (yí)

例

4
Soal 4 (Pertanyaan Audio)
你会做饭吗？
Nǐ huì zuòfàn ma?
Apakah kamu bisa memasak?
A. 我 不会 (wǒ bú huì) = Saya tidak bisa ✓ B. 我 吃 饺子 (wǒ chī jiǎozi) = Saya makan pangsit C. 做 面条儿 (zuò miàntiáor) = Membuat mi
💡 Penjelasan Materi: Pertanyaan dimulai dengan modal verba 会 (huì) yang berarti "bisa/dapat". Cara menjawab yang paling tepat dan logis untuk pertanyaan "Apakah kamu bisa memasak?" adalah menyatakan bisa atau tidak bisa, yaitu 我不会 (wǒ bú huì).
5
Soal 5 (Pertanyaan Audio)
今天星期几？
Jīntiān xīngqījǐ?
Hari ini hari apa?
A. 休息 (xiūxi) = Istirahat B. 星期四 (Xīngqīsì) = Hari Kamis ✓ C. 五 口 人 (wǔ kǒu rén) = Ada 5 orang (dalam keluarga)
💡 Penjelasan Materi: Kata tanya 几 (jǐ) digunakan untuk menanyakan jumlah atau hari (dalam konteks hari ke- berapa). Kata kunci pada pertanyaan adalah 星期几 (xīngqījǐ - hari apa), sehingga jawaban yang menunjuk pada nama hari adalah 星期四 (Xīngqīsì - Hari Kamis).

Soal 9 (Kalimat & Pertanyaan Audio)
Kalimat (Audio):

(Wǒ bābɑ qīshí suì le, tā zài jiā lǐ.)

NOMOR 2 第 2 题
Tanya Kewarganegaraan Guru
Pertanyaan · 问
Nǐ de Zhōngwén lǎoshī shì nǎ guó rén?
你的中文老师是哪国人？
"Guru bahasa Mandarin Anda berasal dari negara mana?"
Jawaban · 答
Wǒ lǎoshī / tā shì Yìnní rén.
我老师 / 她是印尼人。
"Guru saya / Dia adalah orang Indonesia."
💡 Penjelasan Materi: Kata 哪国人 (nǎ guó rén) menanyakan kewarganegaraan atau asal negara. 印尼人 (Yìnní rén) berarti orang Indonesia.
NOMOR 3 第 3 题
Tanya Nama Teman Sekelas
Pertanyaan · 问
Nǐ de tóngxué jiào shénme míngzi?
你的同学叫什么名字？
"Siapa nama teman sekelasmu?"
Jawaban · 答
Wǒ de tóngxué jiào Dara.
我的同学叫 Dara。
"Teman sekelasku bernama Dara."
💡 Penjelasan Materi: Kata 同学 (tóngxué) berarti teman sekelas. Pola kalimat kepemilikan menggunakan 的 (de), yaitu 你的同学 (nǐ de tóngxué - teman sekelasmu) dan dijawab dengan 我的同学 (wǒ de tóngxué - teman sekelasku).
NOMOR 4 第 4 题
Tanya Status Pelajar
Pertanyaan · 问
Nǐ shì xuésheng ma?
你是学生吗？
"Apakah kamu seorang pelajar/mahasiswa?"
Jawaban · 答
Wǒ shì xuésheng.
我是学生。
"Saya adalah seorang pelajar/mahasiswa."
💡 Penjelasan Materi: Kalimat ini menggunakan partikel tanya 吗 (ma) di akhir kalimat untuk membentuk pertanyaan Ya/Tidak (Yes/No Question). Dijawab dengan 是 (shì - adalah) menegaskan identitas diri sebagai pelajar (我是学生).
NOMOR 5 第 5 题
Tanya Kepemilikan Teman Tiongkok
Pertanyaan · 问
Nǐ yǒu Zhōngguó péngyou ma?
你有中国朋友吗？
"Apakah kamu memiliki teman dari Tiongkok?"
Jawaban · 答
Wǒ méiyǒu Zhōngguó péngyou.
我没有中国朋友。
"Saya tidak memiliki teman dari Tiongkok."
💡 Penjelasan Materi: Kata kerja 有 (yǒu) berarti "memiliki/ada", sedangkan bentuk negasi untuk kepemilikan selalu menggunakan 没有 (méiyǒu - tidak memiliki/tidak ada), bukan *不有*.
